Задание 1.
Монолитный фронтенд разделен на микрофронтенды:

1. Аутентификация. Экран авторизации и регистрации.
2. Карточки. В этот микрофронтенд входит функционал по управлению карточками.
3. Профиль. В этот микрофронтенд входит функционал управления профилем пользователя
4. Хост. Этот микрофронтенд зодержит в себе лэйаут, маршрутизацию и общий стейт для микрофронтендов
5. Библиотека состояния. Выделена отдельная зашаренная между микрофронтендами библиотека с React Context API для использования общего состояния.

Обоснование.
Были выбраны три домена (аутентификация, карточки, профиль) на них я и разделил приложение. Эти три домена могут развиваться независимо друг от друга и команды могут сосредоточиться на одной определенной предметной области.
